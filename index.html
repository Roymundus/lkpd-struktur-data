2. Tujuan Pembelajaran

  1. Menjelaskan fungsi Search Algorithm dalam menemukan data.
  2. Menerapkan Linear Search dan menganalisis kondisi Binary Search.
  3. Menerapkan dan membandingkan Bubble Sort dan Selection Sort.
  4. Menerapkan prinsip LIFO pada Stack dan FIFO pada Queue.
  5. Menentukan operasi Push, Pop, Enqueue, dan Dequeue.
  6. Menganalisis penerapan algoritma dan struktur data pada kehidupan sehari-hari dan lingkungan kerja.

Ingat: Linear Search = cek satu per satu. Binary Search = bagi area pencarian menjadi dua secara berulang dan membutuhkan data terurut. Bubble Sort = bandingkan data berdekatan. Selection Sort = cari data terkecil/terbesar dari bagian yang belum terurut.
PROBLEM BASED LEARNING

4. Permasalahan Utama — “Satu Hari di Bengkel”

Bayangkan kalian menjadi bagian dari tim teknisi sebuah bengkel pemesinan. Pada awal jam kerja ditemukan empat masalah:

  1. Teknisi kesulitan menemukan komponen tertentu.
  2. Ukuran komponen di gudang tidak tersusun dengan baik.
  3. Benda kerja ditumpuk sehingga benda terakhir diletakkan harus diambil terlebih dahulu.
  4. Siswa menunggu giliran menggunakan mesin dan harus dilayani berdasarkan urutan kedatangan.
“Gunakan cara berpikir komputasional untuk membuat pengelolaan data, komponen, dan antrean di bengkel menjadi lebih teratur.”
